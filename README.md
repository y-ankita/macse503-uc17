Enterprise Data Engineering Capstone Project
UC17: Enterprise Human Capital Management Data Platform (EHCMDP): Building a Unified Workforce & HR Analytics Platform

Business Background:
ABC Global Enterprises Ltd. is a multinational organization with over 75,000 employees operating across multiple countries and business units. The Human Resources department manages workforce operations through an Enterprise Human Capital Management (HCM) platform integrating Recruitment, Employee Onboarding, Payroll, Attendance, Leave Management, Performance Management, Learning & Development, Employee Self-Service, and Workforce Planning. Every day, thousands of HR transactions are generated from HRMS, Payroll Systems, Attendance Devices, Recruitment Portals, Learning Management Systems (LMS), Performance Management Systems, Employee Portals, and Identity Management Systems. Since these systems operate independently, the organization faces challenges in maintaining a unified employee view, monitoring workforce productivity, tracking recruitment pipelines, managing payroll accuracy, improving employee retention, and generating enterprise-wide HR insights.

Setup & to run locally:
Clone the repo:
git clone https://github.com/y-ankita/macse503-uc17.git

Setup PostgreSQL and PDI Spoon:
- Install PostgreSQL locally and create a new database.
- Update the DB connection details (host, port, username, password, db name) in the config files.
- Install Pentaho Data Integration (Spoon) and add the PostgreSQL JDBC driver to its lib folder.
